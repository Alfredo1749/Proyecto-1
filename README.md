Este proyecto es un sistema de gestión académica que permite automatizar la administración de cursos, estudiantes, evaluaciones y calificaciones.  
El objetivo es reducir errores, mejorar la organización y ofrecer reportes útiles para el proceso educativo.  

- Registro de usuarios (**estudiantes** e **instructores**).  
- Creación y administración de cursos.  
- Inscripción de estudiantes en cursos.  
- Creación de evaluaciones (exámenes, tareas).  
- Registro y consulta de calificaciones.  
- Generación de reportes (ej. estudiantes con promedio bajo).  

---
Programas usados
- **Lenguaje:** Python 3.10+  
- **Paradigma:** Programación Orientada a Objetos (POO)  
- **Control de versiones:** Git & GitHub
